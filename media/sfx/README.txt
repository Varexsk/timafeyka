Звуки показа.

Часть файлов уже скачана командой `npm run audio` (applause, drumroll, tada) —
это записи из общественного достояния, источники перечислены в media/CREDITS.md.
Остальные звуки синтезируются в браузере, отдельные файлы для них не нужны.

Хочешь свои — положи сюда mp3/ogg/wav с такими именами, они заменят и то, и другое:

  correct.mp3    — верный ответ
  wrong.mp3      — мимо
  point.mp3      — начислили балл
  drumroll.mp3   — барабанная дробь
  tada.mp3       — туш на награждении
  applause.mp3   — аплодисменты
  whoosh.mp3     — смена номера
  click.mp3      — щелчок

Длинные записи обрезать не нужно: экран сам берёт начало звука и мягко уводит
его в тишину.

Фоновая музыка лежит рядом, в media/music — там достаточно одного файла.
Ничего настраивать не надо: всё подхватится при следующем открытии экрана.
